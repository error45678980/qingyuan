# 2026-10-24

## 情感泡泡 · 复杂交互组件升级

在 `情感泡泡项目` 原有设计系统上新增四组交互组件，全部零外部依赖、复用 `:root` token：

- `static/js/ui.js`：Toast（堆叠/悬停暂停/滑动关闭）、焦点陷阱 + ESC 栈、数字滚动、localStorage 安全读写。
- `static/js/cmdk.js`：⌘K 命令面板，本地模糊搜索（子串优先 + 子序列），分组、高亮、最近使用、ARIA combobox。
- `static/js/insights.js` + `GET /api/insights`：统计卡、堆叠柱（7/14/30 天、图例筛选、悬停提示）、环形图、24 小时热力条、自动洞察结论。
- `static/js/wall-drag.js`：占位符 + FLIP 拖拽重排、顺序持久化（`eb-wall-order:<user>`）、Alt+方向键键盘重排、右键快捷菜单。

后端：`database.py` / `database_pg.py` 新增 `get_insight_data()`；`server_app.py` 新增 `/api/insights`（只回 `(情绪, epoch ms)`，按浏览器本地时区分桶）与 `_epoch_ms()`。
样式：`style.css` 追加「复杂交互组件」区块 + `--color-surface-pop`、`--color-success` token；侧栏/弹窗补 `visibility` 以退出 Tab 顺序。

验收：`test_smoke.py` 新增洞察接口断言并通过；用 puppeteer-core + 本机 Chrome 验证 87 个泡泡下的拖拽、键盘重排、命令面板、图例筛选、焦点归还、移动端无横向溢出，控制台零报错。演示数据只写入临时库 `%TEMP%/eb_demo.db`，生产库 `server_data/` 未改动。
