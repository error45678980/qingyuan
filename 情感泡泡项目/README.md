# 情感泡泡 💭 — 全球情感交流软件

> 一个运行在 Windows 上的全球社交应用，中央服务器负责泡泡同步和交流。
> 情感以"泡泡"的形式发布，可被所有人看到和回复。

---

## 📂 项目文件导航

| 文件路径 | 说明 |
|----------|------|
| `DOCS/01_需求文档.md` | 项目完整需求规格说明 |
| `DOCS/02_技术设计规范.md` | 技术架构、技术选型、设计规范 |
| `DOCS/03_开发执行步骤.md` | 分阶段开发步骤与里程碑 |
| `DOCS/04_界面原型说明.md` | UI界面设计与交互说明 |
| `开发日志/日志索引.md` | 所有开发日志的索引 |

---

## 🚀 如何使用本文件

1. **新加入项目** → 先阅读 `DOCS/01_需求文档.md` 了解项目全貌
2. **开始开发** → 按 `DOCS/03_开发执行步骤.md` 逐步推进
3. **每天工作** → 在 `开发日志/` 中记录当天完成事项和待办事项
4. **遇到技术问题** → 查阅 `DOCS/02_技术设计规范.md`

---

## 🛠️ 快速启动（开发完成后）
```bash
pip install -r requirements.txt
python server.py   # 启动中央服务器
python src/main.py  # 启动客户端
```

## 🎯 项目核心规则
- ✅ 采用中央服务器架构，支持全球用户发布与交流
- ✅ 客户端保留本地缓存、离线阅读和本地保存功能
- ✅ 轻量级、易部署、逐步迭代
- ✅ 每天记录开发日志
