## 🛠️ 快速启动

```bash
pip install -r requirements.txt
python run_web.py
```

启动后浏览器打开 **http://127.0.0.1:5000**（注册需邀请码，见 `config/secrets.local.py`）。
也可直接双击 `启动软件.bat`。
