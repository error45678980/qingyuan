# 情缘 — 多电脑联机测试指南

## 🎯 目标

通过中央服务器让多台电脑上的「情缘」用户能实时看到对方的泡泡、回复和聊天。

## 🔧 方式一：本地服务器模式（推荐）

1. 在一台电脑上打开项目根目录，运行：

```bash
python server.py
```

2. 在同一台电脑或任意其他电脑上运行客户端：

```bash
python src/main.py
```

3. 输入昵称进入，客户端会自动连接到本地中央服务器。

> 默认服务器地址：`http://127.0.0.1:5000`

## 🌐 方式二：远程服务器模式

如果你有一台可访问的远程服务器，可以将客户端指向该服务器地址。

**步骤：**
1. 在远程机器上运行 `python server.py`。
2. 在客户端机器上设置环境变量：

```cmd
set QINGYUAN_SERVER_URL=http://your-server-host:5000
```

3. 然后启动客户端：

```bash
python src/main.py
```

> 客户端将在启动时自动连接到指定的中央服务器，并同步全球泡泡内容。

## 💡 测试建议

1. **先启动服务器** — 服务器启动后再打开客户端。
2. **再开启多个客户端** — 每个客户端输入不同昵称测试发布与回复。
3. **测试全球泡泡** — 任一客户端发布泡泡，其他客户端应可看到。
4. **测试回复与对话** — 回复泡泡并进入私密聊天，确认所有客户端同步历史记录。

## ❓ 常见问题

**Q: 看到“离线”提示？**
A: 请确认中央服务器正在运行且 `QINGYUAN_SERVER_URL` 指向正确地址。

**Q: 服务器端口被占用？**
A: 请检查是否有其他程序占用 `5000` 端口，或通过环境变量启动自定义服务器地址。

**Q: 如何连接远程服务器？**
A: 设置 `QINGYUAN_SERVER_URL` 环境变量为 `http://服务器地址:5000`。
