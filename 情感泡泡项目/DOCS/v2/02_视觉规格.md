# 情缘 v2.0 — 视觉参考规格

> 由交付总监整理。参考图来自本项目历史设计稿（`DOCS/v2/refs/*.png`），
> 这是产品最初想要的样子，当前 PyQt 版本把它退化成了"灰色矩形卡片"。
> **v2.0 的视觉目标：把这套圆形泡泡美学在 PyQt5 里真正实现出来。**

## 一、泡泡墙（ref_wall_light.png / ref_wall_dark.png）

| 元素 | 规格 |
|------|------|
| 背景 | 浅色模式：近白灰（#F7F7FA）带极淡的紫/粉/蓝径向光晕；深色模式：#0B0B12 深底 |
| 泡泡形状 | **正圆**，不是矩形卡片。直径随内容长度在 96px ~ 168px 之间分档（短内容小泡、长内容大泡） |
| 泡泡填充 | 每个情感一组柔和渐变（左上高光 → 主色 → 边缘加深），中心偏亮，边缘有 1px 半透明描边 |
| 光晕 | 泡泡外圈有一层同色柔光（blur 半径约 12-20px，透明度 30-50%），深色模式下更明显 |
| 泡泡内容 | 顶部一个情感 emoji（约 22-28px），下方 2-3 行文字（自动省略号截断），居中 |
| 排版 | **流式布局**：按窗口宽度自动换行，行内居中对齐，泡与泡水平间距约 24px、垂直间距约 20px，相邻泡泡有轻微上下错位（错落感） |
| 动效 | 静止时每个泡泡有极缓慢的上下浮动（±4px，周期 4-7 秒，各自相位随机）；鼠标悬停放大 1.06 倍并增强光晕；点击时轻微回弹 |
| 顶栏 | 左侧品牌「💭 情缘」，右侧：泡泡墙 / 我的 / 昵称 / 在线状态点 / 切换 |
| 筛选 | 一排胶囊 chip（全部 + 6 个情感），选中态为紫底白字，未选中为白底描边 |
| 发布按钮 | 右下角紫色圆形悬浮按钮（60px），带阴影 |

## 二、发布（ref_publish.png）

- 居中弹层卡片（圆角 28px，白底，大阴影），背后泡泡墙高斯模糊压暗
- 字段顺序：内容输入框（多行，占位提示）→ 情感 chip 组（可点选）→ 回复模式两选一卡片（带说明小字）→ 主按钮
- 输入为空时按钮置灰，不弹错误框；实时字数计数（上限 300 字）

## 三、详情

- 左侧保留泡泡墙（模糊），右侧抽屉式详情面板（宽约 420px），圆角只在左侧
- 顶部：返回、情感 tag、作者、时间
- 正文完整展示，不再截断
- 底部操作区：访客看到「回复」输入框；作者看到「已解决（爆破）」与「保留」两个按钮

## 四、对话（ref_chat.png）

- 右侧抽屉（宽约 420px），顶部显示对方昵称 + 关联泡泡摘要
- 对方消息：左对齐、白底、圆角、昵称在上、时间在下
- 我的消息：右对齐、紫色渐变底、白字
- 输入区固定在底部，回车发送，Shift+回车换行

## 六、已知实现陷阱（实测截图验证）

1. **`QFrame { ... }` 选择器会连带 QLabel**：QLabel 继承自 QFrame，所以给卡片写
   `card.setStyleSheet("QFrame { background: white; border-radius: 30px; }")` 时，
   卡片内所有 QLabel 也会被涂上白底 → 每个文字后面出现一块白色方块（登录页实测已复现）。
   **必须用 `QFrame#cardName { ... }` 或 `setObjectName` + `#id` 选择器**，或者干脆
   `paintEvent` 自绘背景、不给容器设 QSS 背景。
2. **`border-radius` 对 QWidget 子类不生效**：只有 QFrame/QPushButton 等原生支持，
   自绘控件必须用 `QPainter.drawRoundedRect` / `drawEllipse`。
3. **离屏截图无字体**：`QT_QPA_PLATFORM=offscreen` 下 `QFontDatabase().families()` 为空，
   文字全部不可见。要拿到真实渲染，用
   `widget.setAttribute(Qt.WA_DontShowOnScreen, True); widget.show(); widget.grab()`
   —— 不弹窗、有字体。`tools/shoot.py` 已封装。
4. **圆角窗口/半透明**：不要用 `WA_TranslucentBackground` 做无边框窗口，Windows 上会
   丢失阴影且拖动卡顿；保持系统边框，圆角只用在内部卡片。
5. **emoji 字体**：`QFont("Segoe UI Emoji")` 在部分 Win10 上缺彩色字形，需 fallback 到
   `"Segoe UI Emoji", "Microsoft YaHei"` 组合，并在绘制时用 `QFontMetrics` 量宽。

## 七、硬性要求

1. 泡泡必须是**画出来的圆**（`QPainter` + `QRadialGradient`），不能用 QSS `border-radius` 模拟
2. 流式布局必须自适应窗口宽度（1200px 宽时约 5-6 列，800px 时 3-4 列）
3. 浮动动画不得占用 CPU 过高（单一定时器驱动全部泡泡重绘，不要每个泡泡一个 QTimer）
4. 离屏截图环境下字体缺失属正常现象，但布局几何必须正确（不得出现重叠/裁切）
