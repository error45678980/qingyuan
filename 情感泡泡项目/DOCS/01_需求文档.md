# 01 需求文档 — 情感泡泡 💭

> 版本：v1.0  
> 最后更新：2025年  
> 状态：已确认 ✅

---

## 一、项目概述

**情感泡泡** 是一款运行在 Windows 上的全球情感交流软件。  
用户可以发布自己的情感需求（以"泡泡"形式），这些泡泡可以被所有使用该软件的人看到。  
用户可以对别人的泡泡进行回复，回复时根据发布者选择的模式进行单次回复或建立短时对话。  
所有数据保存在使用者本地，用户之间通过 P2P 直接通信。

---

## 二、核心功能需求

### 2.1 用户身份

| 项目 | 说明 |
|------|------|
| 用户标识 | 每台设备 = 一个用户 |
| 身份信息 | 仅需设置一个**昵称** |
| 注册/登录 | **不需要** — 输入昵称即进入主界面 |

### 2.2 情感分类标签

发布帖子时必须选择一个情感分类：

| 分类 | 标签 |
|------|------|
| 😊 开心 | Happiness |
| 😢 难过 | Sadness |
| 🥺 孤独 | Loneliness |
| 😰 焦虑 | Anxiety |
| 💡 寻求建议 | Advice |
| 🗣️ 找人倾诉 | Talk |

> 分类可扩展，后续可根据需要增加。

### 2.3 帖子（泡泡）发布

- 用户输入**文字内容**
- 选择**情感分类标签**
- 选择**回复模式**（单次回复 / 短时对话框）
- 点击发布 → 泡泡出现在界面上

### 2.4 回复模式

| 模式 | 说明 |
|------|------|
| **单次回复** | 每个用户只能对该泡泡回复一次，不建立对话 |
| **短时对话框** | 回复后，回复者与发布者之间建立私密对话框，可多轮交流 |

### 2.5 帖子展示

- 泡泡按**发布时间倒序排列**（最新的在最上面）
- 支持**按情感分类筛选**查看
- 每个泡泡以**气泡形式**显示，不同情感分类用不同颜色/风格

### 2.6 帖子生命周期

```
发布泡泡 → 被其他人看到 → 被回复 → 发布者评估
                                               ↓
                          ┌── 需求已解决 → 🎈 泡泡炸了（删除动画）→ 消失
                          │
                          └── 对话有价值 → 📦 申请保留
                                               ↓
                                    ┌── 设置为公开可见（持续展示）
                                    │
                                    └── 私密保存（仅自己可见）
```

#### 删除（泡泡炸了）
- 发布者确认"需求已解决"
- 泡泡播放**爆破动画**后消失
- 所有对话随之结束

#### 保留
- 发布者认为对话有价值
- 保留内容：帖子原文 + 全部对话记录
- 可选择：
  - **公开可见**：保留后其他用户仍然能看到
  - **私密保存**：仅自己可见的本地记录

### 2.7 用户发现机制

- **不主动搜索其他用户**
- 所有互动通过泡泡进行
- 用户只能看到他人发布的泡泡
- 点击泡泡 → 查看详情 → 进行回复
- 只有在回复后才与对方建立 P2P 连接

## 三、非功能需求

### 3.1 数据存储
- 所有数据保存在**用户本地**
- 使用轻量级本地数据库（SQLite）

### 3.2 网络通信
- P2P 直接连接，无需中央服务器
- 用户之间直接传输数据

### 3.3 视觉风格
- **梦幻、治愈系**风格
- 泡泡浮动界面
- 不同情感分类使用不同颜色/效果
- 泡泡删除时有**爆破动画**
- 柔和渐变、半透明效果

### 3.4 性能要求
- 最小代价优先，逐步迭代
- 软件轻量，适合普通 Windows 电脑运行

## 四、用户界面流程

```
[启动软件]
    ↓
[输入昵称页面] → 输入昵称后进入
    ↓
[主界面 — 泡泡墙]
    ├── 顶部：筛选栏（按情感分类筛选）
    ├── 中部：泡泡列表（按时间排列）
    ├── 右下角：发布按钮（+）
    │
    ├── 点击 [+发布] → [发布泡泡页面]
    │   ├── 输入文字内容
    │   ├── 选择情感分类
    │   ├── 选择回复模式（单次/对话框）
    │   └── 点击发布 → 返回主界面
    │
    ├── 点击 [某个泡泡] → [泡泡详情页]
    │   ├── 查看帖子内容
    │   ├── 查看已有回复
    │   ├── [回复按钮]（如果是单次模式）
    │   ├── [发起对话按钮]（如果是对话框模式）
    │   ├── [标记已解决]（仅发布者可见）→ 泡泡炸了
    │   └── [申请保留]（仅发布者可见）
    │
    └── 如果是对话框模式回复者
        └── [对话窗口] → 私密聊天界面
```
