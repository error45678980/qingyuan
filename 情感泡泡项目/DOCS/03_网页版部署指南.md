# 网页版部署指南（情感泡泡）

> 本文说明如何在本机运行网页版，以及如何通过 Cloudflare Tunnel 免费上线公网。

---

## 一、本机运行

```bash
# 1. 安装依赖（首次）
pip install -r requirements.txt

# 2. 生产模式启动（推荐，多线程）
python run_web.py

# 3. 或开发模式启动（自动重载，仅本机调试用）
python server.py
```

启动后浏览器打开：**http://127.0.0.1:5000**

**注册邀请码**：见 `config/secrets.local.py` 里的 `INVITE_CODE`。

> ⚠️ 不要把邀请码写进任何文档、截图或聊天记录——文档会被提交、会被转发。
> 如果你已经这样做过，请更换 `INVITE_CODE` 并只私下告知使用者。

> 说明：`server.py` 与 `run_web.py` 现在启动的是**同一个网页版应用**，区别只是
> `server.py` 用 Flask 自带开发服务器（仅调试），`run_web.py` 用 waitress（生产多线程）。

## 三、通过 Cloudflare Tunnel 免费上线

> 前置：一个 Cloudflare 账号（免费）。Tunnel 会把你的本机服务暴露到一个公网域名，
> **无需公网 IP、无需备案**（域名用 Cloudflare 托管的即可）。

### 方式 A：快速试用（临时地址，重启会变）

```bash
# 下载 cloudflared（Windows）
# https://github.com/cloudflare/cloudflared/releases

# 先启动你的网站（另一个窗口）
python run_web.py

# 生成一个临时公网地址
cloudflared tunnel --url http://127.0.0.1:5000
```

终端会输出一个 `https://xxxx.trycloudflare.com` 地址，发给朋友即可访问。

### 方式 B：正式上线（固定域名）

1. 在 Cloudflare 后台添加一个你自己的域名（或使用已有的）。
2. 登录并创建隧道：

```bash
cloudflared tunnel login
cloudflared tunnel create emotion-bubble
```

3. 编写配置文件 `~/.cloudflared/config.yml`：

```yaml
tunnel: <你的隧道ID>
credentials-file: C:\Users\<你>\.cloudflared\<隧道ID>.json

ingress:
  - hostname: 情感泡泡.你的域名.com
    service: http://127.0.0.1:5000
  - service: http_status:404
```

4. 绑定域名并启动：

```bash
cloudflared tunnel route dns emotion-bubble 情感泡泡.你的域名.com
cloudflared tunnel run emotion-bubble
```

5. 让隧道常驻（可选，Windows 开机自启）：

```bash
cloudflared service install
```

## 四、合规提醒

- 本项目是「用户产生内容（UGC）」的社交类站点，**国内个人备案极可能被驳回**。
- 使用 Cloudflare Tunnel + 境外/Cloudflare 托管域名，可**免备案**上线。
- 上线后注意：邀请码只发给信任的人；必要时在 `config/secrets.local.py` 更换邀请码。

## 五、安全说明（已实现）

- 身份一律从会话（session）读取，**不信任前端提交的 author/sender 等字段**。
- 密码用 `werkzeug` 哈希存储（数据库里看不到明文）。
- 每个请求独立数据库连接，并发不串数据。
- 全站 CSRF 防护 + 登录限流（60 秒内最多 5 次失败）。
- 聊天通道按会话隔离：非会话双方访问他人通道 → 403。
- 跑在 Cloudflare Tunnel 后面已启用 `ProxyFix`，https 与真实 IP 正确。
